# Promotion records directory

Stable capability promotion records (ME-RV-087) live here as JSON files
validated by `schemas/promotion-record.schema.json` and enforced by
`scripts/validate_registry.py`.

Naming:

- `\<capabilityId\>.json`, or
- `\<capabilityId\>@\<version\>.json`

No capability is currently `stable`. Do not add unsigned placeholder records
to fake promotion closure.
