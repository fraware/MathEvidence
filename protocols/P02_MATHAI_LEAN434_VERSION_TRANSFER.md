# MATH-AI Lean 4.34.1 version-transfer robustness protocol

**Status:** FROZEN BEFORE EXECUTION  
**Date:** 2026-09-30  
**Evidence class:** post-review robustness arm  
**Source construction:** accepted P02 native-v2 corpus generator  
**Transferred classifier:** frozen hardened v2 classifier  
**Target Lean release:** `leanprover/lean4:v4.34.1`  
**Lean tag commit:** `5045d0056413266e57c625dcd7c365b10e377c52`

This arm is designed after reviewer feedback and is not preregistered. Its sole
purpose is to test whether the accepted construction and operational rule
transport from Lean 4.14.0 to Lean 4.34.1 while holding the generated source
artifacts and classifier logic fixed.

## Frozen source construction

The arm reuses the exact first 32 lattice cases generated by
`scripts/p02_native_v2_raw.py`. Before execution, the runner recomputes the
entire original 34-case corpus projection and requires its digest to equal the
accepted frozen digest
`sha256:fe356ed2f5d4bcf653c5cedaa37922e2248547434fe30b746fbcf10ca73bc199`.
The two outside-domain controls are excluded from this version-transfer
denominator.

No source text is rewritten for the new Lean version. In particular,
`UNKNOWN_TYPE` remains exactly the accepted source perturbation under the
release's default `autoImplicit` setting.

## Frozen transferred prediction

The primary empirical signatures are transferred unchanged:

- SOURCE_CORRUPTION -> FRONTEND_REJECT
- UNKNOWN_TYPE -> TOOLCHAIN_ACCEPT_TARGET_MATCH (native-inert)
- INVALID_PROOF -> ENVIRONMENT_OR_ELAB_REJECT
- PROHIBITED_PLACEHOLDER -> TOOLCHAIN_ACCEPT_POLICY_REJECT
- WRONG_TARGET -> TOOLCHAIN_ACCEPT_TARGET_MISMATCH

The active precedence is transferred unchanged:

`FRONTEND_REJECT < ENVIRONMENT_OR_ELAB_REJECT < TOOLCHAIN_ACCEPT_POLICY_REJECT < TOOLCHAIN_ACCEPT_TARGET_MISMATCH < TOOLCHAIN_ACCEPT_TARGET_MATCH`.

The 32 state predictions, 80 one-mechanism removal predictions, and original
edge categories are fixed from these signatures. No signature or precedence is
relearned from Lean 4.34.1 outcomes.

## Denominators

- 32 state executions: all five-bit subsets exactly once.
- 80 successor executions: every present mechanism removed independently.
- Expected primary-design categories under the transferred rule:
  - 30 visible-active removals,
  - 34 later masked-active removals,
  - 16 native-inert removals.

The accepted Lean 4.14.0 denominators remain separate and are never pooled into
this arm.

## Execution boundary

Lean is invoked directly from the exact `v4.34.1` elan toolchain. The runner
records `lean --version` and requires both version `4.34.1` and commit
prefix `5045d0056413`. This arm intentionally isolates Lean release transport;
it is not a current-mathlib project replication.

All diagnostics, target-probe results, classifier `UNKNOWN` outcomes, state
mismatches, and intervention mismatches are retained. Evidence is committed
before any success criterion is enforced.

Publication promotion requires a structurally separate recomputation of all 32
state predictions and all 80 edge predictions. A failed transfer is reported
with the same priority as a clean transfer.
